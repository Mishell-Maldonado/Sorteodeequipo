*Sorteo de Equipos*
## Descripción

Este proyecto realiza un sorteo aleatorio de participantes o equipos a partir de una lista de nombres ingresados por el usuario.

## Funciones del sistema

## El programa se encarga de:

 Agregar participantes a una lista.
 Almacenar los nombres ingresados por el usuario.
 Realizar un sorteo aleatorio entre los participantes.
 Seleccionar un resultado de forma aleatoria usando una función de azar.
 Mostrar el resultado del sorteo en pantalla.
 Permitir realizar nuevos sorteos con la misma lista o una nueva.
 Funcionamiento

## El usuario ingresa los nombres de los participantes.
Los nombres se guardan en una lista.
El sistema ejecuta el sorteo aleatorio.
Se muestra el participante o equipo seleccionado.
